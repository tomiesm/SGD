# ARTIFACTS.md

Every artifact the pipeline produces, the script that produces it, a short
description, and the manuscript figure/section it supports. Generated artifacts are
written to `results/` (gitignored, regenerated by the recipe); the final figure
PDFs are written to `figures/`.

Run order and per-step commands are in [`README.md`](README.md); verification
that each artifact matches the manuscript is in
[`REPRODUCTION_REPORT.md`](REPRODUCTION_REPORT.md).

## Notes

- **Rebuilt orphans.** `d11_spatial_patterns_called8.json`,
  `supp_t11_calibration_called8.json` and `d11_mt1h_leave_m1.json` were produced
  in the original analysis by ad-hoc scripts that were never saved. Scripts 12
  and 13 are re-authored, gene-set-parametrised reconstructions; their output is
  verified bit-for-bit against the surviving artifacts (REPRODUCTION_REPORT.md).
- **`visium_human.h5ad`** is written by step 02 and updated in place by steps
  05, 07 and 11. Run the recipe in order so each step sees the expected state.
- **MERFISH** is not used by the manuscript and is not loaded by this pipeline.
