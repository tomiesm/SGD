# Kinematic spatial gradients - replication repository

Analysis code that reproduces every reported number and figure of the manuscript

> **A kinematic interpretation of spatial expression gradients from
> single-snapshot spatial transcriptomics**
> Tomas Iešmantas, Department of Applied Mathematics, Kaunas University of
> Technology. *Manuscript under review (BMC Bioinformatics).*

## What the framework is

Spatial transcriptomics measures gene expression as a function of position in
tissue. This repository estimates per-gene spatial gradients and evaluates
their reproducibility across donors, platforms, and analysis choices. A
kinematic model supplies a conditional interpretation: in a tissue where the
position-conditioned expression field is stationary and mean cell displacement
along an anatomical axis has positive local velocity `v(s)`, the net-production
term satisfies

```
F_i(g) = v(s) * dg_i/ds
```

the steady-state reduction of the advection equation for cell-averaged
expression. The measured statistic is a spatial gradient; the production
interpretation depends on the stated steady-state and flow assumptions. The
framework is evaluated on the live-donor human liver atlas of Yakubovsky et al.
(2026), applied to graded steatosis, and evaluated on the Moor et al. (2018)
crypt-villus dataset.

This repository is **code only**. Run the recipe below against the public
Yakubovsky atlas to regenerate every artifact, the 4 main figures, and the 10
supplementary figures. That the code does reproduce the manuscript's numbers is
documented in [`REPRODUCTION_REPORT.md`](REPRODUCTION_REPORT.md): all ~40
headline numbers reproduce exactly.

## Installation

Python 3.12.

```
pip install -r requirements.txt
```

`cell2location`, `scvi-tools` and `torch` are **optional**. They are needed only
for `python scripts/10_cell2location.py --mode train`, which is GPU-bound
(~2 h). They are commented out at the bottom of `requirements.txt`. The default
`--mode auto` uses the published cached `obs_hep_fraction_c2l.parquet` when it is
available, and `--mode rescore` explicitly selects the deterministic CPU pass
(see `data/README.md`).

Scripts add `src/` to `sys.path` themselves, so no `pip install -e .` is needed
- run them directly from the repository root.

For a small data-free demonstration, open
[`examples/quickstart.ipynb`](examples/quickstart.ipynb). It constructs a
synthetic expression matrix with spatial coordinates, runs the same quantile
binning and slope primitive used by the manuscript, plots the profiles, and
reports monotonicity and correlation diagnostics.

## Data

The input data is **not** in this repository. Download it before running:

- **Yakubovsky live-donor liver atlas** - Zenodo
  [`10.5281/zenodo.17735506`](https://doi.org/10.5281/zenodo.17735506)
  (CC-BY-4.0): raw Visium, Visium HD, and the integrated snRNA-seq reference.
- **Yakubovsky supplementary tables 2, 4, 6, 10, 11** - from the source paper
  ([`10.1038/s41586-026-10377-y`](https://doi.org/10.1038/s41586-026-10377-y))
  supplementary information.
- **Yakubovsky GitHub lipid annotations** - `Loupe_categories/` from the
  `OranYak/Human-liver` repository.
- **Moor 2018 intestinal crypt-villus** - Zenodo
  [`10.5281/zenodo.3403670`](https://doi.org/10.5281/zenodo.3403670): the
  laser-capture-microdissection crypt-villus zonation table, used by the
  second-tissue validation (`scripts/crypt/`).

Place everything under `data/` as described in
[`data/README.md`](data/README.md).

For large inputs or generated outputs stored outside the checkout, set
`SGD_DATA_DIR`, `SGD_RESULTS_DIR`, and/or `SGD_FIGURES_DIR`. Set
`SGD_LOUPE_DIR` only when the Loupe annotation directory is outside one of the
documented data layouts. Exact reproduction requires all 16 Visium samples;
`SGD_ALLOW_PARTIAL=1` is reserved for explicitly non-reproduction development
runs.

## Reproduction recipe

Run from the repository root, in order. Each step reads `data/` (inputs) and
`results/` (a prior step's output) and writes to `results/`; the figure block
writes `figures/`. `ARTIFACTS.md` lists the exact output of each step.

| # | Command | Manuscript |
|---|---|---|
| 1 | `python scripts/01_inventory.py` | (input inventory) |
| 2 | `python scripts/02_load_visium.py` | Methods §Data; 16 samples / 47,828 spots |
| 3 | `python scripts/03_load_visium_hd.py` | Methods §Pre-processing (Visium HD) |
| 4 | `python scripts/04_load_snrna.py` | Methods §Hepatocyte-composition sensitivity (reference) |
| 5 | `python scripts/05_axis_and_confounds.py` | Axis construction + confounds C1-C5; **Fig S1** |
| 6 | `python scripts/06_gradient.py` | Per-gene gradient estimation |
| 7 | `python scripts/07_axis_validation.py` | Four-tier validation; **Fig 1**, **Fig S2** |
| 8 | `python scripts/08_cross_comparisons.py` | Cross-platform / -pipeline / sign-of-correlation; **Fig 2**, **Fig S3** |
| 9 | `python scripts/09_wmatrix_stability.py` | W-matrix stability diagnostics; **Fig 3** |
| 10 | `python scripts/10_cell2location.py --mode auto` | Hepatocyte-composition sensitivity; **Fig S4** *(cached CPU rescore, or GPU training if no cache)* |
| 11 | `python scripts/11_steatosis_model.py` | Steatosis regression + calling rule; **Fig 4A**, **Fig S5** |
| 12 | `python scripts/12_steatosis_patterns.py` | Per-tertile spatial patterns; **Fig 4B**, **Fig S6** |
| 13 | `python scripts/13_calibration.py` | Supp-table calibrations; **Fig 4C**, **Fig S7** |
| 14 | `python scripts/14_gsea.py` | Pathway enrichment; **Fig 4D** |
| 15 | `python scripts/15_steatosis_robustness.py` | exhaustive wild-cluster inference + GLUL-excluded-axis sensitivity; **Tables S1-S2** |
| F | `python scripts/figures/fig1_axis_validation.py` ... `fig4_steatosis.py`, `figS_supp.py`; then `python scripts/crypt/03_figure.py` | renders the 4 main + 10 supplementary figure PDFs |
| 16 | `python scripts/16_verify_outputs.py` | fail-fast audit of cohort, panels, corrected diagnostics, tables, and figure inventory |

**Dependency order:** 1 -> 2 -> {3, 4, 5}; 5 -> 6 -> 7 -> 8; step 9 needs 2 + 3 + 5;
step 10 needs 2 + 4 (or the cached parquet); step 11 needs 2 + 5; steps 12, 13,
14 and 15 need 11. The figure scripts run after all analysis steps, and step 16
runs last. Steps 3, 4 and 10 are the only ones a pure-Visium replicator can skip
- skipping them drops Fig 2A, Fig 3D, Fig S4 and the C4 row of Fig S1.

## Second-tissue evaluation (intestinal crypt-villus)

`scripts/crypt/` applies the framework to a second tissue - the mouse
intestinal crypt-villus axis - as an independent directional-recovery check. It reads only the
Moor et al. (2018) laser-capture-microdissection zonation table (see
[`data/README.md`](data/README.md)) and has no dependency on the liver
pipeline above.

| # | Command | Output |
|---|---|---|
| 1 | `python scripts/crypt/01_marker_recovery.py` | Marker recovery for 15 canonical markers on the 7-zone axis |
| 2 | `python scripts/crypt/02_wmatrix_stability.py` | W-matrix non-identifiability diagnostics |
| 3 | `python scripts/crypt/03_figure.py` | Renders **Fig S10** |

Steps 1 and 2 run in either order and write `results/moor_crypt_results.json`;
step 3 reads that file and renders `figures/figS10_crypt_validation.pdf`. The
second panel reports trajectory PCA rather than a response-label permutation:
permuting response genes only permutes rows of the fitted matrix and is not a
valid aggregate-stability null.
